# Contributing to dotConnect

Thank you for your interest in contributing! Here's how to get started:

## Development Setup

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/dotConnect.git
   cd dotConnect
   ```

3. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Set up local environment (see README.md)

## Making Changes

- Keep commits atomic and well-described
- Follow the existing code style
- Test your changes locally before pushing
- Update documentation if needed

## Before Submitting a Pull Request

- Ensure both frontend and backend work locally
- Run linters: `npm run lint` in frontend
- Test with sample data
- Update README.md if adding features
- Don't commit `.env` files or sensitive data

## Pull Request Process

1. Push to your fork
2. Open a PR against the `main` branch
3. Describe your changes clearly
4. Link any related issues
5. Wait for review and feedback

## Code of Conduct

- Be respectful and constructive
- Help others learn and grow
- Follow existing patterns in the codebase

## Questions?

Feel free to open an issue for discussions or questions!
